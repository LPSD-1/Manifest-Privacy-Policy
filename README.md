# Manifest — Privacy Policy

The published privacy policy for the Android applications **Manifest** and
**Manifest Studio**.

Served by GitHub Pages at:

    https://lpsd-1.github.io/Manifest-Privacy-Policy/

That address is cited by both Google Play listings, so **it must not move.**
Changing it means editing two listings, and a reviewer who reaches a dead link
mid-change can reject the app.

## Why this is a separate repository

The application repository is private and this document is public by
definition. Keeping them apart means the policy can be served without making
anything else public, and without a paid plan — GitHub Pages cannot publish
from a private repository on the free tier.

## Editing it

`index.html` is the whole site. Edit it, commit, push; Pages redeploys in
a minute or so.

**Change the date at the top whenever the text changes.** The policy says the
current version is always at this address, and a stale date makes that a lie
somebody could check.

**Keep it true to the code.** Play cross-checks a privacy policy against the
Data Safety declarations on the listing and rejects disagreements. The sections
on what is recorded, where it goes and which permissions are asked for were
written from the application source, not from a template — if the app changes
what it collects or where it sends it, this changes with it.
